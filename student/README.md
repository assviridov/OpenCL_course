## Упрощенная постановка

Прибор записывает сигнал из **N каналов**, в каждом **M отсчетов**. К каждому каналу
применяется «фильтр»: набор из **K коэффициентов** b (K — нечетное).

По каналу движется **скользящее окно** размера K со сдвигом на один отсчет.
Для каждого положения окна вычисляется r — сумма произведений отсчетов окна
на коэффициенты фильтра (как скалярное произведение). Значение r ставится
в позицию **среднего элемента окна**.

Окно не должно выходить за границы канала. Поэтому отсчеты r, где окно
не помещается, считаются **нулями**.

Для разных каналов используются разные фильтры: в отдельной строке входного файла
для каждого канала записан номер набора коэффициентов — **1 или 2**.

**Найти:** среднее арифметическое всех r по всем каналам
(краевые нули входят в среднее — делить нужно на N·M!), с точностью до 4-го знака.

## Пример из условия (файл `example.txt`)

```
вход:                          выход (массив r):        result
2 5 3                          канал 1: 0 6 9 12 0      3.1500
0.1 0.1 0.1                    канал 2: 0 0.5 1.5 2.5 0
1.0 0.5 -0.5
1 2
10 20 30 40 50
1 2 3 4 5
```

Проверьте руками канал 1: окно с центром в позиции 1 покрывает отсчеты
10, 20, 30 → 10·0.1 + 20·0.1 + 30·0.1 = 6.

## Формат входного файла `input.txt`

```
строка 1: N M K
строка 2: K чисел — коэффициенты фильтра 1
строка 3: K чисел — коэффициенты фильтра 2
строка 4: N чисел 1 или 2 — какой фильтр у каждого канала
далее:    N строк по M чисел — отсчеты
```
Внимание: в оригинальном условии опечатка («1 или 1») — правильные значения **1 или 2**.

аргументов уже написаны (как на занятии). Нужно заполнить:

- **TODO 1** — тело ядра (главная часть работы):
  1. `pad = (K-1)/2` — отступ от края до центра окна.
     Внимание: называть переменную `half` нельзя — в OpenCL это зарезервированный тип!
  2. выбрать фильтр: `sel[ch]==0` → `B0`, иначе → `B1`;
  3. если окно выходит за границы канала (`pos < pad` или `pos >= M - pad`) — `r = 0`;
  4. иначе `r` = сумма `win[k]*b[k]`, `k = 0..K-1`, где `win = A + ch*M + pos - pad`;
  5. записать `R[ch*M + pos] = r`.

- **Часть A** (обязательна): запустить на `example.txt`. Массив r в выводе должен

## Критерии приема

1. Часть A: массив r и result совпадают с примером.
2. Часть B: result совпадает с `FilterCheck` на сгенерированных данных.
3. Короткие ответы на вопросы:

## Сборка

### Windows / Code::Blocks

1. Установите Code::Blocks **с компилятором MinGW** (инсталлятор `...mingw-setup.exe`).
2. Установите OpenCL SDK (например, [OCL_SDK_Light](https://github.com/GPUOpen-LibrariesAndSDKs/OCL_SDK_Light)) — путь из шага 3 подставьте свой.
3. Один раз для всех проектов: **Settings → Compiler → GNU GCC Compiler → Search directories**
   - вкладка **Compiler**: добавьте `<путь к SDK>\include`
   - вкладка **Linker**: добавьте `<путь к SDK>\lib\x86_64`
4. Откройте `OpenCL_hw.workspace`. **Выберите сборочную цель**: на Windows — `Debug`,
   на macOS — `Debug mac` (линковка OpenCL отличается: `-lOpenCL` на Windows,
   `-framework OpenCL` на macOS). Порядок работы: соберите и запустите `FilterGen`
   (создаст `input.txt`), затем `FilterCheck` (эталон), затем свой `FilterCL`.
5. Рабочая папка при запуске задана в `.cbp` как корень папки ДЗ: `FilterGen` создаст
   `input.txt` в корне папки ДЗ (рядом с `OpenCL_hw.workspace`), и `FilterCheck`/`FilterCL` прочитают
   его оттуда. Папки `bin\`, `obj\` внутри проектов — артефакты сборки.

Если глобальные настройки менять не хочется — альтернатива: скопируйте папку
`CL` из SDK в `MinGW\include`, а `OpenCL.lib` из `lib\x86_64` — в `MinGW\lib`,
переименовав в `libOpenCL.a`.

### macOS
```bash
clang++ -O2 -std=c++17 FilterGen/FilterGen.cpp -o fgen
clang++ -O2 -std=c++17 FilterCheck/FilterCheck.cpp -o fcheck
clang++ -O2 -std=c++17 FilterCL/FilterCL.cpp -o fcl -framework OpenCL

# Часть A: данные из условия
cp example.txt input.txt && ./fcl

# Часть B: сгенерированные данные (сверка с эталоном)
./fgen 8 1000 101 7 && ./fcheck && ./fcl
```
